# Admin Import Format

Questions generated by external AI or imported from CSV/JSON must enter as `draft` or `pending_review`. They are never published automatically.

  "batchId": "optional-source-batch-id",

## Review Rules

- Admin verifies correct answer, explanation, source, category, and territorial scope.
- Admin resolves duplicates before publication.
- Admin sets `published` only after human review.
- Outdated legal questions should keep historical exam linkage but be excluded from current training with `validUntil` or `disabled` status.
