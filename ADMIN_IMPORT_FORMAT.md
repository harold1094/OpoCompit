# Admin Import Format

Questions generated by external AI or imported from CSV/JSON must enter as `draft` or `pending_review`. They are never published automatically.

## JSON Batch

```json
{
  "batchId": "optional-source-batch-id",
  "sourceDocument": "document.pdf",
  "questions": [
    {
      "id": "optional-stable-id",
      "oppositionId": "firefighters_es",
      "statement": "Question text",
      "answers": [
        {"id": "a", "text": "Answer A"},
        {"id": "b", "text": "Answer B"},
        {"id": "c", "text": "Answer C"},
        {"id": "d", "text": "Answer D"}
      ],
      "correctAnswerId": "a",
      "explanation": "Explanation shown after finishing/reviewing.",
      "categoryId": "legislation",
      "subcategoryId": null,
      "difficulty": 2,
      "scopeType": "national",
      "country": "ES",
      "autonomousCommunity": null,
      "province": null,
      "municipality": null,
      "specificCallId": null,
      "officialExamId": null,
      "year": 2026,
      "source": "Official exam / manual / law",
      "sourceDocument": "document.pdf",
      "sourcePage": 1,
      "verified": false,
      "status": "pending_review",
      "validFrom": null,
      "validUntil": null
    }
  ]
}
```

`createdBy`, timestamps, territorial keys, and content fingerprints are assigned by the server.
When `batchId` or a question `id` is omitted, the server generates a stable identifier from the
validated content. A batch contains at most 100 questions.

## CSV Conversion

The React admin panel accepts pasted CSV and converts it locally into the same JSON contract before
anything reaches Firebase. Delimiters, quoted commas, and multiline quoted fields are handled by a
CSV parser. Every converted row is forced to `pending_review` and `verified: false`.

Required columns:

```text
oppositionId,statement,answerA,answerB,correctAnswerId,explanation,categoryId,difficulty,scopeType,country,source
```

Optional columns:

```text
id,answerC,answerD,answerE,answerF,subcategoryId,autonomousCommunity,province,municipality,specificCallId,officialExamId,year,sourceDocument,sourcePage,validFrom,validUntil
```

Answers use stable identifiers `a` through `f`; `correctAnswerId` is case-insensitive during CSV
conversion. Numeric fields must contain integers. The converted JSON remains visible for human
inspection before the administrator imports the batch.

## Local Emulator Import

Start the Auth, Firestore, and Functions emulators in one terminal and seed the opposition:

```bash
cd functions
npm run serve
```

In a second terminal:

```bash
cd functions
npm run seed:emulator
npm run import:emulator -- --file fixtures/admin-import.sample.json
```

The versioned Cartagena firefighter exam can be imported into the review queue with:

```bash
cd functions
npm run import:emulator -- --file fixtures/cartagena-firefighters-exam-2026.json
```

This batch contains the 70 ordinary questions and 5 reserve questions from the official
25 April 2026 exam. Topic scope is classified independently from the exam origin: state law is
`national`, operational knowledge is `technical`, Murcia plans and legislation are `autonomic`,
and Cartagena local knowledge is `municipal`. Every question also keeps the shared
`officialExamId` so the original exam can be reconstructed.

The local command creates a disposable emulator-only administrator and calls the same
`importQuestionBatch` endpoint used by a future admin interface. It cannot target a deployed
Firebase project.

## Review Rules

- Admin verifies correct answer, explanation, source, category, and territorial scope.
- Admin resolves duplicates before publication.
- Admin sets `published` only after human review.
- Outdated legal questions should keep historical exam linkage but be excluded from current training with `validUntil` or `disabled` status.
- Reusing a `batchId` with identical content is idempotent; reusing it with different content is rejected.
- Bulk publication or rejection accepts at most 50 selected pending questions and completes atomically.
