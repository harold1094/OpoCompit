# Admin Import Format

Questions generated by external AI or imported from CSV/JSON must enter as `draft` or `pending_review`. They are never published automatically.

## JSON Batch

```json
{
  "batchId": "optional-source-batch-id",
  "sourceDocument": "document.pdf",
  "questions": [
    {
      "id": "optional-stable-id",
      "oppositionId": "firefighters_es",
      "statement": "Question text",
      "answers": [
        {"id": "a", "text": "Answer A"},
        {"id": "b", "text": "Answer B"},
        {"id": "c", "text": "Answer C"},
        {"id": "d", "text": "Answer D"}
      ],
      "correctAnswerId": "a",
      "explanation": "Explanation shown after finishing/reviewing.",
      "categoryId": "legislation",
      "subcategoryId": null,
      "difficulty": 2,
      "scopeType": "national",
      "country": "ES",
      "autonomousCommunity": null,
      "province": null,
      "municipality": null,
      "specificCallId": null,
      "officialExamId": null,
      "year": 2026,
      "source": "Official exam / manual / law",
      "sourceDocument": "document.pdf",
      "sourcePage": 1,
      "verified": false,
      "status": "pending_review",
      "validFrom": null,
      "validUntil": null
    }
  ]
}
```

`createdBy`, timestamps, territorial keys, and content fingerprints are assigned by the server.
When `batchId` or a question `id` is omitted, the server generates a stable identifier from the
validated content. A batch contains at most 100 questions.

## Local Emulator Import

Start the Auth, Firestore, and Functions emulators in one terminal and seed the opposition:

```bash
cd functions
npm run serve
```

In a second terminal:

```bash
cd functions
npm run seed:emulator
npm run import:emulator -- --file fixtures/admin-import.sample.json
```

The local command creates a disposable emulator-only administrator and calls the same
`importQuestionBatch` endpoint used by a future admin interface. It cannot target a deployed
Firebase project.

## Review Rules

- Admin verifies correct answer, explanation, source, category, and territorial scope.
- Admin resolves duplicates before publication.
- Admin sets `published` only after human review.
- Outdated legal questions should keep historical exam linkage but be excluded from current training with `validUntil` or `disabled` status.
- Reusing a `batchId` with identical content is idempotent; reusing it with different content is rejected.
